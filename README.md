# Portafolio de Hanson Chacon

Sitio estatico para presentar perfil profesional, logros, proyectos y stack tecnico.

## Ver localmente

Abre `index.html` en el navegador o ejecuta:

```bash
python3 -m http.server 5500
```

Luego entra a:

```text
http://localhost:5500
```

## Pendientes recomendados

- Cambiar `tu-correo@ejemplo.com` por el correo real en `index.html` y `script.js`.
- Agregar LinkedIn si ya tienes perfil.
- Agregar enlaces reales a los repositorios de Mesa de ayuda y Sistema hospitalario.
- Ajustar el nombre oficial de la maestria si tu universidad usa una variante especifica.
- Subir a GitHub Pages, Vercel o Netlify.
